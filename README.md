# WinRust

Переписанные на Rust системные компоненты Windows 10/11: Проводник, Диспетчер задач,
менеджер служб, системные утилиты и ядро (библиотека доступа к Win32). Цель — не демо,
а повседневный рабочий инструмент: каждое окно делает то же, что делает оригинал.

Всё собирается в один workspace, без сторонних бинарников: только `windows-sys` для
FFI и `eframe/egui` для интерфейса.

## Что уже работает

| Компонент | Файл | Возможности |
|---|---|---|
| **Проводник** | `winrust-explorer.exe` | Вкладки, боковая панель с системными папками, адресная строка с навигацией, список/таблица с сортировкой по имени/размеру/дате/типу, иконки файлов через `SHGetFileInfoW`, копирование/вырезание/вставка/удаление в корзину, переименование, создание папок, контекстное меню, «Открыть с помощью», «Запуск от имени администратора», «Свойства», поиск, отображение скрытых файлов, сохранение состояния вкладок |
| **Диспетчер задач** | `winrust-taskmgr.exe` | Процессы с CPU% (реальное семплирование), памятью, **диском** и **сетью** по PID, группировка по приложению, сортировка по любой колонке, завершение/приостановка/возобновление, приоритет, «Открыть расположение файла», «Свойства», вкладки Производительность (графики CPU/память/ядро), Автозагрузка (с реальным включением/отключением через `StartupApproved`), Пользователи, Сеть (TCP/UDP-соединения), Службы |
| **Службы** | `winrust-services.exe` | Полный список Win32-служб и драйверов, фильтр, состояние, тип запуска (в т.ч. отложенный автозапуск), путь к исполняемому файлу, учётная запись, зависимости, **редактирование описания**, старт/стоп/пауза/возобновление, диалог свойств, точные ошибки Win32 при отсутствии прав |
| **Системные утилиты** | `winrust-sysctl.exe` | Обзор системы (ОС, CPU, RAM, uptime), переменные среды с редактированием и `WM_SETTINGCHANGE`, автозагрузка, схемы электропитания с переключением, сеть, ядро/версии, драйверы, отчёт о поддержке (диагностика) |
| **Ядро** | `winrust-core` | Безопасные RAII-обёртки над Win32: процессы, службы, файловая система, реестр, сеть, оболочка, иконки, пользователь/токен, система, широкие строки, коды ошибок |
| **Лаунчер** | `WinRust.exe` | Единое окно для запуска всех компонентов |

## Сборка

Нужен Rust 1.75+ и Windows 10/11 (x64). Кросс-компиляция не поддерживается — используются
нативные API.

```powershell
cargo build --release
# бинарники появятся в target\release\
```

Запуск конкретного компонента:

```powershell
.\target\release\WinRust.exe              # лаунчер
.\target\release\winrust-explorer.exe
.\target\release\winrust-taskmgr.exe
.\target\release\winrust-services.exe
.\target\release\winrust-sysctl.exe
```

Для действий, требующих прав администратора (запуск/остановка служб, изменение чужих
процессов), запускайте соответствующий .exe от имени администратора.

```
  winrust-services/   Менеджер служб

.github/workflows/    сборка, тесты, clippy, релиз на windows-latest
```

## Технические заметки

* **Никаких unsafe-утечек в UI.** Весь `unsafe` сосредоточен в `winrust-core`; каждый
  хэндл закрывается через RAII, включая `HKEY` (через `RegCloseKey`).
* **CPU%** считается по дельте `GetProcessTimes` между снимками, а не по загрузке системы —
  так же, как это делает настоящий Диспетчер задач.
* **Диск по процессу** — из `GetProcessIoCounters` (`ReadTransferCount + WriteTransferCount`).
* **Сеть по процессу** — из extended TCP statistics (`Set/GetPerTcpConnectionEStats`,
  `TCP_ESTATS_DATA_ROD_v0`), агрегированная по PID.
* **Автозагрузка** — чтение `…\CurrentVersion\Run` плюс `StartupApproved\Run` (12-байтовый
  блоб: `0x02` включено, `0x03` отключено), редактирование через `RegSetValueExW`.
* **Версия/издатель файлов** — `GetFileVersionInfoW` + `VerQueryValueW` (`VS_FIXEDFILEINFO`).
* **Даты изменения файлов** — собственный `civil_from_days` (алгоритм Ховарда Хиннанта),
  потому что `FileTimeToSystemTime` отсутствует в windows-sys 0.59.

## CI

`.github/workflows/build.yml` на каждый пуш собирает fmt/test/build/clippy/release на
`windows-latest` и коммитит результаты в `docs/ci/build/*.txt` — это единственный способ
увидеть вывод сборки в средах без локального toolchain.
